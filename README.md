Mini Project Web Developer Team 💻

Mini Project Web Developer Team merupakan sebuah website yang dibuat menggunakan HTML, CSS, dan JavaScript untuk menampilkan informasi mengenai anggota atau tim yang memiliki peran dalam pengembangan sebuah website. Website ini dirancang dengan tampilan yang sederhana, menarik, dan mudah digunakan sehingga pengguna dapat melihat informasi anggota tim secara lebih terstruktur. Setiap anggota ditampilkan menggunakan foto dan informasi yang berkaitan dengan profil atau perannya dalam tim. Project ini dibuat sebagai penerapan dasar Web Development, khususnya dalam penggunaan struktur HTML untuk membangun halaman, CSS untuk mengatur tampilan dan tata letak, serta JavaScript untuk memberikan fungsi dan interaksi pada website.

Fitur Utama
Menu Utama
1. Halaman Utama: Menampilkan halaman utama website Web Developer Team sebagai tampilan awal ketika website dibuka.
2. Daftar Anggota Team: Menampilkan kumpulan anggota yang tergabung dalam tim web developer dengan menggunakan foto dan informasi masing-masing anggota.
3. Profile Member: Setiap anggota memiliki tampilan profil yang dapat memberikan informasi mengenai anggota dalam tim.
4. Tampilan Visual: Website menggunakan gambar anggota sebagai elemen visual agar informasi team lebih menarik dan mudah dikenali.
5. Responsive Layout: Struktur halaman dirancang agar elemen-elemen website dapat ditampilkan dengan lebih teratur pada ukuran layar yang berbeda.
6. JavaScript Interaction: JavaScript digunakan untuk memberikan fungsi atau interaksi tertentu pada halaman website sehingga tidak hanya berupa halaman HTML statis.
7. Navigation: Pengguna dapat berpindah atau mengakses bagian website yang tersedia dengan lebih mudah melalui struktur halaman yang telah dibuat.
Alur Sistem
Website Dimulai: Pengguna membuka file index.html melalui browser.
Memuat Halaman: Browser membaca struktur HTML kemudian memuat CSS dan JavaScript yang digunakan oleh website.
Menampilkan Tampilan Utama: Sistem menampilkan halaman utama Web Developer Team kepada pengguna.
Menampilkan Data Team: Website menampilkan daftar anggota team beserta gambar masing-masing anggota.
Memilih Anggota: Pengguna dapat melihat anggota team yang tersedia dan informasi yang ditampilkan pada halaman.
Menampilkan Informasi: Ketika pengguna melakukan interaksi pada bagian anggota atau elemen tertentu, JavaScript dapat memproses aksi tersebut sesuai fungsi yang telah dibuat.
Pengaturan Tampilan: CSS mengatur posisi, ukuran, jarak, font, gambar, dan berbagai elemen visual agar halaman terlihat lebih rapi.
Interaksi Pengguna: Pengguna dapat melakukan navigasi dan berinteraksi dengan elemen-elemen yang tersedia pada halaman.
Menampilkan Hasil: Sistem memberikan tampilan atau informasi sesuai dengan interaksi yang dilakukan pengguna.
Website Selesai Digunakan: Setelah melihat informasi anggota dan menggunakan fitur yang tersedia, pengguna dapat berpindah ke bagian lain atau menutup website.
